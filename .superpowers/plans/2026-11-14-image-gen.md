# `/gen` Image Generation & Explicit OpenRouter Model Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the `/gen [aspect_ratio] <prompt>` text-to-image command using OpenRouter's Image API, and remove default OpenRouter models so both `/gen` (`OPENROUTER_IMAGE_MODEL`) and link-preview decision filtering (`OPENROUTER_DECISION_MODEL`) require explicit model + API key configuration to enable.

**Architecture:** Remove `DEFAULT_DECISION_MODEL` in `src/Config.ts` and expose optional trimmed `openrouterApiKey`, `openrouterDecisionModel`, and `openrouterImageModel` (plus `ImageGenConfig` slice). Gate `DecisionFilter` / `LinkPreview` user-image extraction on both `openrouterApiKey` and `openrouterDecisionModel`, and split `/gen` into `ImageGenParser.ts`, `ImageGenClient.ts` (`Context.Service` + `HttpFetchError` passthrough), and `ImageGen.ts` (silent when disabled, `isSelfMessage`, ratio hint on empty prompt), wired in `src/index.ts`.

**Tech Stack:** Bun 1.4.4, TypeScript (`tsc`), Effect 4 (`effect`, `effect/http`), `@snowluma/sdk`, `bun:test`.

**Spec:** `.superpowers/specs/2026-11-14-image-gen-design.md`

## Global Constraints

- Relative imports MUST include explicit `.ts` extensions (`allowImportingTsExtensions: true`).
- Tagged errors (`Schema.TaggedError`) MUST include `{ readonly brand: unique symbol; }` as the second type parameter (`effecttsgo/schema-class-missing-brand`).
- Message handlers MUST call `isSelfMessage(event)` at entry and isolate failures with `Effect.catch` / `Effect.catchDefect`.
- HTTP tests MUST use `makeTestHttpClient` from `test/TestHttpClient.ts` (never mock global `fetch`); config tests MUST use `ConfigProvider.fromEnvRecord` (never mutate `process.env`).
- Commit messages MUST follow Linux Kernel style (no Conventional Commits).

## Review Focus

1. Non-ratio colon tokens as first word (e.g. `/gen 12:30 的街头`, `/gen 21:9 cinema`) MUST NOT be treated as `aspect_ratio` and MUST remain part of `prompt`.
2. Full-width colon + irregular whitespace (e.g. `/gen   16：9\n  赛博朋克猫`) MUST normalize `：` to `:`, extract `aspectRatio: "16:9"`, and preserve the remaining prompt.
3. Empty prompt (`/gen`, `/gen   `, `/gen 16:9`, `/gen 16：9  `) when enabled MUST reply `[请输入提示词，例如：/gen 16:9 一只橘猫（支持比例：1:1、4:3、3:4、16:9、9:16）]` without calling `ImageGenClient`.
4. OpenRouter returning `data: []`, missing `b64_json`, or `media_type: "image/svg+xml"` MUST fail with `ImageGenApiError` and reply `[生图失败]`.
5. Either feature with `OPENROUTER_API_KEY` set and its model (`OPENROUTER_IMAGE_MODEL` / `OPENROUTER_DECISION_MODEL`) unset or blank MUST treat that feature as disabled (`DecisionFilter` skips API & user-image download silently; `/gen` replies `[生图功能未启用]` without calling `ImageGenClient`), and self-sent messages produce zero replies.
