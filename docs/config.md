# 配置与部署指南

Sakurako 的运行依赖环境变量配置（基于 `.env` 文件）以及部分离线静态资源。本文档面向机器人管理员与私有化部署者，统一汇总核心连接参数、可选增强功能、静态资源初始化脚本以及本地持久化存储要求。

---

## 环境变量配置

在项目根目录下创建 `.env` 文件，或在容器环境中直接注入以下环境变量。完整的变量参考可查看项目根目录下的 `.env.example`。

### 1. 核心连接配置

| 环境变量                | 必填 | 默认值                          | 说明                                                  |
| :---------------------- | :--- | :------------------------------ | :---------------------------------------------------- |
| `SNOWLUMA_WS_URL`       | 否   | `ws://snowluma.orb.local:3001/` | SnowLuma / OneBot v11 服务端 WebSocket 正向服务地址。 |
| `SNOWLUMA_ACCESS_TOKEN` | 是   | 无                              | 用于 WebSocket 连接鉴权的 Access Token。              |

### 2. 可选功能增强配置

部分功能支持接入第三方服务以解锁更高的请求配额或智能决策能力：

| 环境变量             | 必填 | 默认值                 | 说明                                                                                                                                                 |
| :------------------- | :--- | :--------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------- |
| `SAUCENAO_API_KEY`   | 否   | 无                     | SauceNao 以图搜图 API Key。未配置时可使用免费基础配额；配置后可享有更高的请求频次上限与每日查询额度。                                                |
| `OPENROUTER_API_KEY` | 否   | 无                     | OpenRouter API Key。配置后将启用基于大语言模型的决策过滤器，用于链接预览的语义去重评估与动态截断。若未配置，链接预览仍正常工作，仅跳过智能过滤判定。 |
| `OPENROUTER_MODEL`   | 否   | `~typesafe/jev-latest` | 用于链接预览决策评估的模型标识。仅在配置了 `OPENROUTER_API_KEY` 时生效。                                                                             |

### 3. 开发与测试隔离配置

为了便于开发调试或在生产环境中隔离测试群聊，支持开启开发者模式：

| 环境变量       | 必填 | 默认值  | 说明                                                                                                                                 |
| :------------- | :--- | :------ | :----------------------------------------------------------------------------------------------------------------------------------- |
| `DEV_MODE`     | 否   | `false` | 设置为 `true` 时启用开发隔离模式。                                                                                                   |
| `DEV_GROUP_ID` | 否   | 无      | 指定允许响应的群聊 ID（整型数字）。当 `DEV_MODE=true` 时，机器人将仅在指定群内响应各类指令与消息，私聊或其它群聊的消息将被静默忽略。 |

## 静态资源准备

为保证部分高级图文功能的离线运行与高效渲染，需在首次启动或构建部署前运行以下资源准备脚本：

### 1. 统计图表渲染字体（MiSans）

消息统计排行榜（`/stat` 与 `/stat all`）会将排版渲染为紧凑深色数据表格图片。该功能默认依赖 MiSans 字体：

```bash
bun run download-font
```

- **脚本行为**：自动从小米官方 CDN 下载并解压 `MiSans-Normal.ttf` 至 `assets/fonts/` 目录。
- **缺失影响**：若未下载字体文件，消息统计指令在生成卡片时将无法正常加载字体排版。
- **版本控制**：字体文件已被 `.gitignore` 忽略，无需纳入代码版本库。

### 2. Danbooru 中英文标签对照数据库

Danbooru 图片检索（`/dbr`）支持中文标签检索、拼写容错与角色重排。该功能依赖离线对照数据库：

```bash
bun run download-tags
```

- **脚本行为**：从开源项目拉取最新中英文对照数据并构建索引，保存至 `assets/danbooru-tags.sqlite`（约 24 MB）。
- **缺失降级**：若未下载该数据库，机器人启动时会记录 Warning 警告日志并自动降级运行；此时 `/dbr` 仍可正常工作，但仅支持直接使用英文标签检索。

## 数据持久化与存储

机器人运行过程中产生的状态与数据库文件保存在本地，容器化部署或跨版本更新时需妥善持久化挂载：

| 路径            | 作用                                                       | 迁移与持久化建议                                                                                         |
| :-------------- | :--------------------------------------------------------- | :------------------------------------------------------------------------------------------------------- |
| `data/stats.db` | 群消息统计（发言数、媒体、链接、互动数）的 SQLite 数据库。 | **必须持久化**。表结构在服务启动时由增量迁移机制自动维护。容器部署时请将宿主机目录挂载至容器内 `data/`。 |
| `assets/`       | 存储下载的字体与离线标签数据库。                           | 推荐持久化挂载，避免容器重启或重新构建时重复下载外部资源。                                               |
