# 图片生成（`/gen`）

Sakurako 支持通过 `/gen` 命令调用 OpenRouter 图像生成接口（`POST /api/v1/images`），根据文本提示词生成图片并直接回复到聊天中。

## 启用条件

该功能默认关闭，无内置默认模型。需在环境变量中**同时配置**：

- `OPENROUTER_API_KEY`
- `OPENROUTER_IMAGE_MODEL`（例如 `recraft/recraft-v4.1-flash-v2:free`）

若未同时配置这两项，发送 `/gen` 时机器人将回复 `[生图功能未启用]`。

## 触发方式

在机器人所在的群聊或私聊会话中发送：

```text
/gen [比例] <提示词>
```

- **默认画幅**：不指定比例时，直接将 `/gen` 后的完整文本作为提示词发送，由模型自动决定比例（例如 `/gen 一只戴墨镜的橘猫`）。
- **指定比例**：当首个空白分隔词为受支持的比例（支持半角 `:` 与全角 `：`）时，自动提取为 `aspect_ratio`，剩余文本作为提示词（例如 `/gen 16:9 赛博朋克猫娘` 或 `/gen 16：9 赛博朋克猫娘`）。
- **防误吞机制**：仅识别受支持的离散比例 `1:1`、`4:3`、`3:4`、`16:9`、`9:16`；类似 `/gen 12:30 的街头` 或 `/gen auto mobile` 中的首词不会当作比例剥离，而是完整保留在提示词中。
- **群聊兼容**：支持 `@机器人` 或回复消息触发，前导 `@` 与回复引用片段会自动剥离。

## 异常与提示信息

| 触发场景                                                    | 机器人回复提示                                                                    |
| ----------------------------------------------------------- | --------------------------------------------------------------------------------- |
| 未同时配置 `OPENROUTER_API_KEY` 与 `OPENROUTER_IMAGE_MODEL` | `[生图功能未启用]`                                                                |
| 未提供提示词（如仅发送 `/gen` 或 `/gen 16:9`）              | `[请输入提示词，例如：/gen 16:9 一只橘猫（支持比例：1:1、4:3、3:4、16:9、9:16）]` |
| OpenRouter 触发请求频率限制（429）                          | `[生图请求过于频繁，请稍后再试]`                                                  |
| 接口异常、网络超时、空响应或返回非栅格格式（如 SVG）        | `[生图失败]`                                                                      |
