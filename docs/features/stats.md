# 消息统计

为了让群友和管理员直观了解群内活跃动态与交流偏好，同时杜绝聊天明文记录带来的隐私泄露隐患，Sakurako 提供了轻量、低侵入的消息统计功能。该功能在后台静默累计群成员的消息计数，并支持主动查询群排行榜与个人统计。

## 功能特性

- **严格隐私保护**：仅做离散计数与群名片映射，**绝不记录、解析或持久化任何聊天文字明文、媒体附件或链接内容**。
- **四大统计维度**：
  - **总发言量**：群聊内发送的各类消息总条数。
  - **媒体消息**：包含图片、语音、视频、贴图表情或图文混合的消息（文件上传不计入）。
  - **包含链接**：消息正文中包含 HTTP/HTTPS 网页链接。
  - **互动次数**：群内戳一戳（拍一拍）及对消息添加的表情回应（Reaction）。
- **自然日分桶**：数据统一按中国标准时间（UTC+8，`Asia/Shanghai`）按自然日分桶归档，兼顾近 30 天与历史累计的精确聚合。
- **现代化图表呈现**：排行榜基于 Satori 与 Sharp 渲染为高质量的紧凑深色数据表格卡片，内置 MiSans 字体支持，手机端清晰易读。

---

## 触发方式与指令

统计功能仅在**群聊会话**中生效（私聊消息不计入统计亦不响应查询指令）。

### 1. 群排行榜 (`/stat`)

在群聊中直接发送以下指令：

```text
/stat
```

- **默认范围**：查询本群**最近 30 天**的活跃排行榜。
- **回复形式**：以图片形式直接发送，渲染 Option B 高密度数据表格，包含 Top 15 成员排名、群名片、总发言条数、媒体数、链接数与互动数。
- **空数据提示**：若本群近 30 天内没有任何记录，机器人回复文本提示 `本群暂无统计数据。`。

### 2. 历史总榜 (`/stat all`)

在群聊中发送：

```text
/stat all
```

- **统计范围**：统计该群自机器人启用统计功能以来的**历史全量累计数据**。
- **回复形式**：同为数据表格图片卡片，表头副标题展示为“历史累计”。

### 3. 个人统计 (`/me`)

在群聊中发送：

```text
/me
```

- **回复形式**：纯文本引用回复，同时呈现个人“最近 30 天”与“历史累计”在各项指标上的双周期对比与群内排位。
- **回复示例**：

```text
📊 个人群聊统计 (近 30 天 / 历史累计)
- 消息总计：1,623 / 5,420 条 (排名第 3 / 2)
- 媒体消息：420 / 1,280 条
- 包含链接：189 / 450 条
- 互动次数：280 / 890 次
```

若发送者在本群内尚无任何发言记录，各项数值显示为 `0`，排名显示为 `-`。

## 防刷与冷却机制

由于 `/stat` 与 `/stat all` 会调用图像渲染引擎（Satori 矢量布局 + Sharp PNG 编码），为避免频繁查询造成系统负载抖动，机器人内置了**群级别 5 秒冷却时间**：

- 在同一群聊中，若在 5 秒内连续发送 `/stat`，后续请求将被静默忽略；
- 冷却期结束后发送的指令将重新正常生成最新榜单。

## 部署与资源配置

### 字体资源准备

排行榜卡片默认使用 MiSans 字体。在首次运行或部署前，可运行项目内置的字体下载脚本获取字体文件：

```bash
bun run download-font
```

该脚本会自动从小米官方 CDN 下载并解压 `MiSans-Normal.ttf` 至 `assets/fonts/` 目录。字体文件已被 `.gitignore` 排除，无需纳入 Git 版本控制。

### 数据库存储

统计数据存储在项目根目录下的 SQLite 数据库 `data/stats.db` 中：

- 数据库表结构由 `SqliteMigrator` 自动维护，服务启动时会自动检查并应用增量迁移；
- 该文件包含本地数据，已被 `.gitignore` 自动忽略，备份容器或迁移时请妥善保留 `data/` 目录。
