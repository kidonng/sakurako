# Danbooru 图片检索与智能标签匹配

Sakurako 支持通过 `/dbr` 命令从 Danbooru 检索精选高质量 SFW 插画。功能内置离线中英文标签对照库（33 万条），支持中文翻译、拼写纠错与复合词重排，降低标签记忆与拼写门槛。

## 触发方式

在机器人所在的群聊或私聊会话中发送：

```text
/dbr [可选搜索词]
```

- **无参数**：发送 `/dbr` 直接获取随机 SFW 活跃插画；
- **中文关键词**：支持中文标签（如 `/dbr 白发` 或 `/dbr 初音未来`），自动映射为 Danbooru 英文标签；
- **英文纠错与重排**：支持轻微拼写失误容错（如 `white_hai` -> `white_hair`）以及角色名顺序重排（如 `miku_hatsune` -> `hatsune_miku`）；
- **标签数量限制**：Danbooru 未登录接口单次最多支持 2 个普通标签。若解析出的标签超过 2 个，机器人将回复提示。

## 回复格式

检索成功时，机器人发送图文并附带帖子网页直链，标题与标签自动翻译为中文：

### 1. 搜索词与中文标签不一致

当用户输入与实际搜索标签对应的中文译名不一致时（如输入英文标签、拼写纠错或缩写），首行增加 `🔍 [中文标签]` 回显：

```text
🔍 [中文标签]
[中文标题]
https://danbooru.donmai.us/posts/:id
[图片]
```

示例：

```text
🔍 白发 猫耳
原创 画师 artist_name
https://danbooru.donmai.us/posts/12345
[图片]
```

### 2. 搜索词完全对应或无搜索词

若输入内容与实际检索词对应的中文一致（例如输入 `白发 猫耳` 且实际检索标签即为 `white_hair cat_ears`），或未提供搜索词时，直接展示标题、直链与图片：

```text
泄矢诹访子 (东方Project) 画师 moni_monico
https://danbooru.donmai.us/posts/12459835
[图片]
```

### 3. 标题中文化与作品名去重规则

- **角色与版权去重**：单角色或多角色属于同一作品系列时（如多位角色均来自《学园偶像大师》），自动剥离角色名中的作品后缀，统一在作品栏展示（如 `仓本千奈、篠泽广 (学园偶像大师 等 1 部) 画师 kousuke0912`）；
- **跨作品联动**：若多个角色来自不同作品，保留各自角色名中的作品后缀（如 `博丽灵梦（东方Project）、莫娜（原神） (东方Project 等 1 部) 画师 artist_name`）；
- **连接符中文化**：画师前缀调整为 `画师 `，多角色与多画师采用中文顿号 `、` 连接，超出数量时提示 `等 N 位` / `等 N 部`；
- **优雅降级**：若作品无角色/画师标签，标题自动回退展示为 `#ID`（如 `#12345`）；若无对照库或查无中文译名，自动回退使用英文标签。

## 异常与提示信息

| 触发场景                           | 机器人回复提示                        |
| ---------------------------------- | ------------------------------------- |
| 解析出的普通标签数量超过 2 个      | `[标签数量超出限制，最多支持 2 个]`   |
| 提供了搜索词但未匹配到任何有效标签 | `[未找到匹配的标签]`                  |
| Danbooru 检索无匹配结果（404/204） | `[未找到符合条件的图片]`              |
| Danbooru 触发请求频率限制（429）   | `[Danbooru 请求过于频繁，请稍后再试]` |
| 网络异常或接口服务故障             | `[Danbooru 接口请求失败]`             |
| 结果中未包含有效图片直链           | `[未获取到有效图片链接]`              |

## 数据源与维护

标签对照库依赖开源项目 `ffdkj-Danbooru_Tag-Chinese-English-Translation-Table`。

### 首次配置（推荐）

运行以下命令下载并初始化本地对照数据库（约 24MB）：

```bash
bun run download-tags
```

该脚本会将数据库保存至 `assets/danbooru-tags.sqlite` 并建立高性能索引。

### 优雅降级说明

若本地尚未下载数据库，机器人仍可正常启动运行，并记录 Warning 日志；此时 `/dbr` 进入降级模式，透传用户输入的英文标签进行检索。
