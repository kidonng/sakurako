# Danbooru 图片检索与智能标签匹配

Sakurako 支持通过 `/dbr` 命令从 Danbooru 检索精选高质量 SFW 插画。功能内置离线中英文标签对照库（33 万条），支持中文翻译、拼写纠错与复合词重排，降低标签记忆与拼写门槛。

## 触发方式

在机器人所在的群聊或私聊会话中发送：

```text
/dbr [可选搜索词]
```

- **无参数**：发送 `/dbr` 直接获取随机 SFW 活跃插画；
- **中文关键词**：支持中文标签（如 `/dbr 白发` 或 `/dbr 初音未来`），自动映射为 Danbooru 英文标签；
- **英文纠错与重排**：支持轻微拼写失误容错（如 `white_hai` -> `white_hair`）以及角色名顺序重排（如 `miku_hatsune` -> `hatsune_miku`）；
- **标签数量限制**：Danbooru 未登录接口单次最多支持 2 个普通标签。若解析出的标签超过 2 个，机器人将回复提示。

## 回复格式

检索成功时，机器人按 Danbooru 官方格式发送图文消息：

### 1. 搜索词经过转换/纠错

当实际使用的英文标签与用户输入不一致时，首行增加 `🔍 [实际搜索词]` 回显：

```text
🔍 white_hair
[Danbooru 官方格式标题]
[图片]
```

示例：

```text
🔍 white_hair cat_ears
original drawn by artist_name
[图片]
```

### 2. 搜索词未发生转换或无搜索词

直接展示标题与图片：

```text
reisen udongein inaba (touhou) drawn by nacht musik
[图片]
```

若作品无角色/画师标签，标题自动回退展示为 `#ID`（如 `#12345`）。

## 异常与提示信息

| 触发场景                           | 机器人回复提示                        |
| ---------------------------------- | ------------------------------------- |
| 解析出的普通标签数量超过 2 个      | `[标签数量超出限制，最多支持 2 个]`   |
| 提供了搜索词但未匹配到任何有效标签 | `[未找到匹配的标签]`                  |
| Danbooru 检索无匹配结果（404/204） | `[未找到符合条件的图片]`              |
| Danbooru 触发请求频率限制（429）   | `[Danbooru 请求过于频繁，请稍后再试]` |
| 网络异常或接口服务故障             | `[Danbooru 接口请求失败]`             |
| 结果中未包含有效图片直链           | `[未获取到有效图片链接]`              |

## 数据源与维护

标签对照库依赖开源项目 `ffdkj-Danbooru_Tag-Chinese-English-Translation-Table`。

### 首次配置（推荐）

运行以下命令下载并初始化本地对照数据库（约 24MB）：

```bash
bun run download-tags
```

该脚本会将数据库保存至 `assets/danbooru-tags.sqlite` 并建立高性能索引。

### 优雅降级说明

若本地尚未下载数据库，机器人仍可正常启动运行，并记录 Warning 日志；此时 `/dbr` 进入降级模式，透传用户输入的英文标签进行检索。
