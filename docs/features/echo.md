# 复读（Echo）

Sakurako 提供了基础的文本应答（Echo）功能，可作为机器人的心跳与连通性验证，用于快速确认机器人在线状态与消息收发链路是否正常。

## 触发方式

在机器人所在的群聊或私聊会话中，直接发送：

```text
喵喵喵
```

## 回复行为

- **回复内容**：机器人将直接回复文本：
  ```text
  喵喵喵
  ```
- **回复形式**：直接发送普通文本消息（非引用回复）。

## 规则与限制

- **严格全字匹配**：消息内容必须严格等于 `"喵喵喵"`。
  - 首尾带有空白字符（例如 `" 喵喵喵 "`）不会触发。
  - 附带标点符号、前后缀或其它指令（例如 `"喵喵喵！"`、`"/echo 喵喵喵"`）不会触发。
  - 包含子串或增减字符（例如 `"喵喵"`、`"喵喵喵喵"`）不会触发。
- **全场景支持**：群聊（`group`）与私聊（`private`）消息均可正常响应。
- **防死循环机制**：内置防环路保护（`isSelfMessage`），机器人会自动忽略自身账号发送的消息，避免在消息广播或同步场景下产生无限自复读。
