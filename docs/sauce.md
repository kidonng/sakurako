# 图片来源（以图搜图）

当在聊天中想要了解某张图片的出处时，Sakurako 支持通过以图搜图功能快速检索图片的原始作者、作品名与跳转链接，方便确认插画作者、动画出处或推文来源。

## 触发方式

在机器人所在的群聊或私聊会话中，**回复/引用**包含图片的消息，并发送：

```text
/sauce
```

- **严格匹配**：指令必须为严格的 `/sauce`，带有额外文本参数（如 `/sauce 123`）不会触发。
- **群聊兼容**：在 QQ 群中点击回复时，客户端自动追加的 `@原作者` 不会影响指令触发。
- **多图选取**：若引用的消息中包含多张图片，机器人默认提取并检索**第一张图片**。

## 回复格式

检索成功且结果达到可信相似度阈值（对比 SauceNao 的 `minimum_similarity`）时，机器人将通过引用回复返回出处信息：

### 1. 包含作者与外部链接（如 Pixiv 等插画）

```text
[作品标题] by [作者]
[来源链接]
```

示例：

```text
Sakura Blossom by ArtistA
https://www.pixiv.net/artworks/12345678
```

### 2. 无明确作者（如动画番剧截图）

```text
[番剧名称与集数]
[来源链接]
```

示例：

```text
Fate/Zero EP.01
https://anidb.net/anime/8160
```

### 3. 无外部链接的条目

若检索结果缺少外部跳转链接，机器人仅输出标题与作者行，省略链接行，避免产生空行或无效占位。

## 异常与提示信息

当检索流程出现非预期情况时，机器人会通过引用回复给出对应提示：

| 触发场景                              | 机器人回复提示               |
| ------------------------------------- | ---------------------------- |
| 发送 `/sauce` 时未引用任何消息        | `未在引用的消息中找到图片`   |
| 引用的消息中不包含任何图片            | `未在引用的消息中找到图片`   |
| 未检索到结果，或匹配项相似度过低      | `未找到相似度较高的图片来源` |
| SauceNao 接口网络超时、服务故障或超额 | `查询失败，请稍后重试`       |

## 配置说明（可选）

管理员可在环境配置文件 `.env` 中配置专属 SauceNao API Key：

```bash
# SauceNao API Key (可选，配置后可提高查询限额)
SAUCENAO_API_KEY=your_saucenao_api_key_here
```

- **未配置 Key**：仍可直接使用以图搜图服务，适合低频测试与日常使用。
- **配置 Key**：可使用账户对应的更高请求速率与每日配额，减少出现频繁请求受限的情况。
